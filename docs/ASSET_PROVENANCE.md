# HANDSHIFT asset provenance

Both raster assets were generated with Codex's built-in image generation tool
on 29 August 2026 and then copied into the project. No runtime asset CDN or
public model pack is used.

## `public/assets/skyline.png`

Use case: `stylized-concept`. A panoramic, road-level Australian-inspired
city skyline transitioning from coral sunset to indigo night, with a clean
distant silhouette, atmospheric haze, no foreground vehicles, no text, no
logos and no watermark. This is used as the game horizon matte.

## `public/card.png`

Use case: `stylized-concept`. Cinematic third-person key art of one unbranded
sport motorcycle threading a survivable gap between a sedan and truck on a wet
blue-hour expressway, using midnight, coral and cyan lighting. It contains no
text, letters, logos or watermark. The selected output was resized to
1200 by 630 pixels for link previews.
